# тестовый сид

набор для разработки и тестирования бота знакомств
имена и описания вымышлены и не относятся к людям на фотографиях
не выдавайте эти записи за реальные анкеты пользователей

## файлы

- `seed.json` — основной json в корне репозитория
- `photos/alt/` — 10 фотографий для типа 1
- `photos/goth/` — 10 фотографий для типа 2
- `photos/traumacore/` — 10 фотографий для типа 3
- `sources.json` — происхождение каждого файла и контрольная сумма sha256
- существующая папка `images/` оставлена без изменений и не используется новым сидом

## схема

```json
[
  {
    "type": 1,
    "names": ["алиса"],
    "descriptions": ["вымышленное описание"],
    "photos": ["https://raw.githubusercontent.com/stryzhka/date-bot-pics/master/photos/alt/01.jpg"]
  }
]
```

пример выше сокращён
в настоящем файле три объекта и в каждом ровно по 10 имён описаний и фотографий

- `type: 1` — альтушки
- `type: 2` — готки
- `type: 3` — фотографические референсы с настроением traumacore

все имена и описания написаны строчными буквами без знаков препинания
`photos` содержит прямые ссылки на jpeg в этом репозитории
массивы являются независимыми пулами а не биографиями изображённых людей

## сбор фотографий

источник — pinterest
для типов 1 и 2 использованы выдачи точных запросов `альтушки` и `готки`
запрос `traumacore aestetics` сохранён в исходном написании
его выдача была просмотрена но состояла преимущественно из коллажей надписей и непортретных изображений
для получения портретов третьей категории поиск был расширен запросами с тем же словом traumacore
точный поисковый запрос для каждой выбранной фотографии записан в `actual_query`
исходно запрошенный вариант находится в `requested_query`

фотографии проверены на декодирование приведены к jpeg с ограничением размера и просмотрены визуально
из подборки исключены очевидные рисунки текстовые коллажи явная нагота и изображения с заметными травмами
среди выбранных файлов нет точных дубликатов по sha256
это не гарантирует что на разных фотографиях изображены разные люди

pinterest возвращал в том числе непрозрачные идентификаторы результатов вида `e1_...`
они сохранены без изменений в `pinterest_result_id`
для таких результатов `pin_url` оставлен `null` поскольку постоянная ссылка на конкретный пин не подтверждена
для проверки происхождения используйте `search_url` `image_url` и `original_page` если она указана

## ограничения

возраст изображённых людей разрешение на повторную публикацию и исходное фотографическое происхождение независимо не подтверждены
визуальный просмотр не доказывает совершеннолетие и не исключает обработку или генерацию изображения
этот набор не предоставляет лицензии на чужие фотографии
не используйте его в публичных анкетах или рекламе без отдельной проверки прав и согласий

traumacore здесь не диагноз и не характеристика изображённых людей
это направление визуального самовыражения связанное с переживаниями а не единая музыкальная или модная субкультура
для текстов взяты только визуальные мотивы фотографии зерно приглушённые цвета дневниковость и тихие пространства
вымышленные описания не приписывают людям диагнозы травматический опыт или потребность в спасении
